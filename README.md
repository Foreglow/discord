A twilight-inspired dark theme for Discord using BetterDiscord/Vesktop.

***Note:** Official installation may differ from the previews above.*

## Installation

### BetterDiscord

1. Install [BetterDiscord](https://betterdiscord.app/)
2. Copy `foreglow.theme.css` to your BetterDiscord themes folder:
   - **Windows**: `%AppData%\BetterDiscord\themes\`
   - **macOS**: `~/Library/Application Support/BetterDiscord/themes/`
   - **Linux**: `~/.config/BetterDiscord/themes/`
3. Enable the theme in Discord → Settings → BetterDiscord → Themes

### Vesktop

1. Install [Vesktop](https://vesktop.dev/)
2. Copy `foreglow.theme.css` to your Vesktop themes folder:
   - **Windows**: `%AppData%\Vesktop\themes\`
   - **macOS**: `~/Library/Application Support/Vesktop/themes/`
   - **Linux**: `~/.config/Vesktop/themes/`
3. Enable the theme in Vesktop → Settings → Themes
